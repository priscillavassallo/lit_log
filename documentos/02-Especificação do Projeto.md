## Histórias de Usuários

Com base na análise das personas forma identificadas as seguintes histórias de usuários:

|EU COMO... `QUEM`   | QUERO/PRECISO ... `O QUE` |PARA ... `PORQUE`                 |
|--------------------|---------------------------|----------------------------------|
| Leitor | Criar uma conta e acessar o sistema. | Utilizar suas funcionalidades. |
| Leitor | Fazer login no sistema. | Acessar minha conta de forma segura. |
| Leitor | Buscar livros, autores e listas. | Encontrar conteúdos de interesse. |
| Leitor | Visualizar informações detalhadas de um livro. | Decidir se quero lê-lo. |
| Leitor | Visualizar informações sobre autores. | Conhecer melhor os escritores e suas obras. |
| Leitor | Avaliar livros e escrever opiniões. | Compartilhar minha experiência de leitura. |
| Leitor | Criar e organizar listas de livros. | Organizar minhas leituras e interesses. |
| Leitor | Registrar livros como lidos ou em leitura. | Controlar meu progresso de leitura. |
| Leitor | Visualizar meu histórico de leitura. | Revisar o que já li ao longo do tempo. |
| Leitor | Manter uma lista de livros desejados. | Planejar futuras leituras. |
| Leitor | Visualizar perfis de outros usuários. | Conhecer outros leitores. |
| Leitor | Seguir outros usuários. | Acompanhar suas atividades de leitura. |
| Leitor | Visualizar conteúdos populares e recentes. | Descobrir novas leituras e tendências. |

## Requisitos do Projeto


### Requisitos Funcionais

|ID    | Descrição do requisito               | Prioridade |
|-------|---------------------------------|----|
| RF-01 | O sistema deve permitir cadastro e autenticação de usuários | Alta |
| RF-02 | O sistema deve permitir busca de livros, autores e listas | Alta |
| RF-03 | O sistema deve exibir informações detalhadas de livros, incluindo descrição, capa, avaliações e reviews | Alta |
| RF-04 | O sistema deve exibir informações sobre autores, incluindo biografia e obras publicadas | Alta |
| RF-05 | O sistema deve permitir criação, visualização e organização de listas personalizadas de livros pelos usuários, como favoritos e listas temáticas | Alta |
| RF-06 | O sistema deve permitir que o usuário registre livros como lidos ou em leitura | Alta |
| RF-07 | O sistema deve permitir que o usuário visualize e gerencie seu histórico de leitura | Alta |
| RF-08 | O sistema deve permitir que o usuário adicione livros à lista de desejos para leitura futura | Alta |
| RF-09 | O sistema deve permitir que usuários avaliem livros por meio de reações | Média |
| RF-10 | O sistema deve permitir que usuários escrevam reviews sobre livros | Média |
| RF-11 | O sistema deve permitir que usuários sigam outros usuários | Média |
| RF-12 | O sistema deve exibir conteúdos recentes e populares com base nas atividades dos usuários | Média |

**Prioridade: Alta / Média / Baixa. 

### Requisitos não Funcionais


|ID      | Descrição               |Prioridade |
|--------|-------------------------|----|
| RNF-01 | O sistema deve estar disponível 24 horas por dia                         | Alta       |
| RNF-02 | O sistema deve ser acessível pela Internet                                | Alta       |
| RNF-03 | O sistema deve ser responsivo para diferentes tamanhos de tela           | Média      |
| RNF-04 | O sistema deve ser acessível, garantindo suporte a tecnologias assistivas e boa legibilidade | Alta       |
| RNF-05 | O sistema deve ser compatível com os principais navegadores (Chrome, Firefox e Edge) | Média      |

**Prioridade: Alta / Média / Baixa.
