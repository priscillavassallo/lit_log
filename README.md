# LitLog

`Análise e Desenvolvimento de Sistemas - PUC Minas`

`Desenvolvimento de aplicação web front-end`

`1º semestre/2026`

O Litlog é um projeto acadêmico sobre uma plataforma web para leitores onde as pessoas possam organizar suas leituras, avaliar livros, escrever resenhas, receber recomendações e interagir com outros leitores.
